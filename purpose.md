Этот репозиторий предзназначен для реализации пайплайна по построению, обновлению, верификации документации проекта АС CF при помощи AI агентов. Проект очень большой и является собственность компании , поэтому я не могу перенести его в этот репозиторий.
Ключевые технологии проекта:
- .NET
- Python
- Angular

Проект осуществляет работу по построению финансовых моделей, у него есть распределенный кластер для вычислений на базе Ignite (GridGain) в котором регистрируются некоторые сервисы.

Задача этого проекта составить план по имплементации процесса технического документирования проекта.

Примерный пайплайн:
- Создание структуры документации через парсеры (.net, python, typescript) - шаг должен быть реализован на языке python и быть детерминированным, это шаг который создает структуру (дерево) документации
- На основе дерева создается (или проверяется наличие) иерархия директорий
- Дальше агент итеративно проходит по документам и с использованием tools для парсинга извлекает из кода необходимую информацию о работе того или иного контроллера, сервиса, провайдера, API вызовы и прочие ключевые характеристики


Требования к документации:
- Документация генерируется с кода
- Документация имеет понятную структуру
- В документации содержится описание а не повторение кода
- В документации обязательно приложены ссылки (пути) до конкретной реализации в коде

Документация должна содержать базовые шаблоны для описания тех или иных сущностей. Эти шаблоны будут использоваться агентом для получения примера какой должна быть документация конкретного элемента. Как минимум должны быть шаблоны для:
- Сервис (Service)
- Провайдер (Provider)
- Воркфлоу (Workflow)
- Контроллер (Controller)
